# 文档依赖与知识覆盖

本文件维护写作结构，读者从 [学习入口](../Hi3516CV610_项目学习/README.md) 阅读。以现有编号和文件名为稳定链接，不创建空章节或第二套正文。

## 三条流程的交点

构建链形成应用、SDK/驱动配套、Sensor 适配与调校产物；启动链消费这些产物并建立资源与绑定；逐帧链消费图像并产生压缩码流，再分为固定地址 RTP 和会话式 RTSP。接收结果与故障证据反向定位输入、处理、编码、发送或显示环节。AI、OSD、MP4、无线只在各自有证据的交接处接入。

重写时保留旧文所覆盖的技术主题与练习能力；用纠正后的结论替换误读。参数细节由所属章解释，其他章只保留推理必需的数值并链接过去。第 15 章以完整讲解和迁移问题检验串联能力，第 16 章以查证路径收束，而非再复制一遍教程。
