# Hi3516CV610 图像数据传输项目

本仓库整理 Hi3516CV610 图传应用、厂商媒体示例、SC500AI 适配与学习文档。

两条主要源码入口分别是：

- [自定义 RTP 程序](hi3516firm/new_main2.c)：SC500AI 图像采集、H.265 编码与 RTP/UDP 发送。
- [RTSP 示例](sample_source/rtsp_4m/sample_rtsp.c)：媒体初始化、双通道 H.264 编码及 RTSP 分发。

详细说明从 [项目学习入口](docs/Hi3516CV610_项目学习/README.md) 开始；原有 [全局架构分析](docs/全局架构与技术剖析.md) 同时保留。

## Git 管理范围

源码、头文件、Makefile、配置、脚本、学习文档及项目内的使用说明纳入版本管理。以下依赖一并保留：

- `hi3516firm/sc500ai_1080P_100.bin` 调校文件与 `airtsp/model/` 中的小型模型。
- MP4、RTMP、GB28181 示例直接链接且当前未附完整重建源码的第三方库。
- 普通输入样本及 AI 初始化仍使用的 YUV 占位文件。

SDK、工具链、厂商大型参考资料、镜像、重复归档、编译产物、录制输出和密钥由 [.gitignore](.gitignore) 排除。忽略规则只影响 Git 跟踪，**不删除本地文件**。

这些原有资源需要在其他电脑按原目录补齐：

| 本地资源 | 用途 |
| --- | --- |
| `SDK/`、`交叉编译工具链/` | 目标 SDK、交叉编译器与外层构建环境 |
| `hi3516cv610/`、`辅助文档/` | 厂商 PDF、参考材料和大型开发配套包 |
| `工具/`、`mirror/`、`hi3516firm/` 中的镜像及驱动 | 本地工具、历史交付产物与部署参考 |
| `sample_source/svp/ive/data/input/gmm2/gmm2_352x288_sp400_frm1000.yuv` | 大型 IVE 输入样本 |
| `sample_source/svp/svp_npu/data/model/*.om` | NPU 示例的大型模型 |

学习文档保留原有资料的相对链接；只克隆 Git 仓库时，指向外置厂商资料的链接需补齐文件后才能打开。项目内使用说明 DOCX 保留在仓库中。

`drone.key` 等私密文件不纳入 Git，部署时单独配置。没有采用 LFS，也没有把忽略的本地资料上传到远程。

## 构建与验证边界

Git 初始化只建立版本管理。当前示例仍依赖配套 SDK 和外层构建配置，自定义 RTP 的 Sensor 路径及 PQ API 也需要按实际构建环境整理。现有库、源码、二进制及固件之间的版本关联见学习文档；仓库建立不代表完成交叉编译或板端验证。

本机 Git 使用宝贝云 HTTP 代理 `http://127.0.0.1:10808`；这是开发电脑的联网设置，不是图传程序的目的地址，也不是仓库服务器端口。代理设置不写入项目源码。
